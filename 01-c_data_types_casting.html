📦 C# Data Types

Data Type HE: טיפוס נתונים AR: نوع البيانات
Declaration Blueprint 
// 1. Specify type  2. Name it  3. Assign value
DataType variableName = value;

// Concrete Examples:
int    playerScore = 100;
double runSpeed    = 4.5;
string heroName    = "Nova";
> Statically Typed: Types never change after creation!
Using Variables in Code 
// Declare and display different types:
int    score = 100;
double speed = 4.5;
string hero  = "Nova";

Console.WriteLine($"Hero: {hero}");
Console.WriteLine($"Score: {score}, Speed: {speed}");
> Output: Hero: Nova | Score: 100, Speed: 4.5
💡
Core Idea: Variables are typed data containers. C# is statically typed, meaning each variable has a fixed type that never changes.

🔢 The Core Three: int, double, string

int: מספר שלם / عدد صحيح
int (Integers) 
// Whole numbers only
int lives = 3;
int score = 1250;
int coins = -5;

score += 250;
> No decimals allowed
double (Decimals) 
// Standard decimal numbers
double velocity = 9.81;
double health   = 75.5;
double scale    = 0.5;

health -= 12.2;
> Default decimal type in C#
string (Text) 
// Double quotes for text
string hero = "Shadow";
string rank = "Gold";

// Python "str" is "string" in C#
string info = hero + " - " + rank;
> Output: "Shadow - Gold"
🧠
Rule: Whole numbers use int, fractional decimals use double, and text uses string.

🔄 Type Casting in Action

Casting HE: המרה AR: تحويل الأنواع
Implicit vs. Explicit Cast 
// 1. Implicit (Safe: int ➔ double)
int basePoints = 40;
double total   = basePoints; // Automatic: 40.0

// 2. Explicit (Truncation: double ➔ int)
double exactHp = 19.95;
int roundedHp  = (int)exactHp; // Chops decimals!

Console.WriteLine(roundedHp);
> Output: 19 (Truncates! Does NOT round!)
String Parsing (Input ➔ Numbers) 
// Convert string text into numbers for math:
string inputAge   = "16";
string inputPrice = "14.99";

int age      = int.Parse(inputAge);
double price = double.Parse(inputPrice);

Console.WriteLine(age + 4); // Math works!
> Output: 20
⚠️
Takeaway: Implicit cast is automatic. Explicit (int) truncates fractions. Text requires int.Parse() or double.Parse().

🎯 When Should Casting Be Used?

Syntax Fixes: מניעת שגיאות חישוב / تفادي أخطاء الحساب
Case 1: Fix Integer Division 
// WRONG: int / int discards remainder
double badRatio  = 5 / 2;        // Result: 2.0

// FIXED: Cast one operand to double
double goodRatio = (double)5 / 2; // Result: 2.5

Console.WriteLine(goodRatio);
> Output: 2.5
Case 2: Reading Console.ReadLine() 
// Console input is ALWAYS a string:
Console.Write("Enter level: ");
string rawInput = Console.ReadLine();

// Cast/Parse to int before adding points:
int nextLevel = int.Parse(rawInput) + 1;

Console.WriteLine("Next: " + nextLevel);
> User inputs "4" ➔ Prints: Next: 5
📌
When to cast: 1. Keyboard input math. 2. Preserving division decimals. 3. Dropping decimals for UI pixels.

🧪 Comprehension Check: Predict the Output

Quiz: שאלות הבנה / أسئلة الفهم
Question 1: What prints to console?
double score = 8.95;
int result   = (int)score;
Console.WriteLine(result);
Answer: 8 (Not 9!)
Explicit cast (int) truncates the .95 completely; it never rounds up.
Question 2: Text concatenation or math?
string a = "10";
string b = "20";
Console.WriteLine(a + b);
Answer: "1020"
Because both are string, + joins text. To get 30, use int.Parse(a) + int.Parse(b).
