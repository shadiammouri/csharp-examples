🚦 The C# "if" Statement

Condition HE: תנאי AR: شرط
Syntax Blueprint 
// Condition inside ( ) must evaluate to true/false:
if (booleanCondition)
{
    // Code runs ONLY if condition is true!
}

// Comparison Operators:
// == (equals)       != (not equals)
// >  (greater)      <  (less)
// >= (greater/eq)   <= (less/eq)
> HE: תנאי בוליאני | AR: شرط منطقي
Example 1: Health Alert 
int playerHealth = 18;

// Check if health dropped to critical level:
if (playerHealth <= 20)
{
    Console.WriteLine("⚠️ WARNING: Low Health!");
    Console.WriteLine("Drink a potion immediately!");
}

Console.WriteLine("Game continues...");
> Output: ⚠️ WARNING: Low Health!
💡
Core Idea: If the condition is true, the block inside { } executes. If false, C# completely skips it!

🔀 Two-Way Decisions: if / else

Branching HE: הסתעפות AR: تفريع
Ex 2: Game Age Verification 
int userAge = 15;

if (userAge >= 16)
{
    Console.WriteLine("Access Granted: Welcome to the server!");
}
else
{
    Console.WriteLine("Access Denied: Must be 16 or older.");
}
> Output: Access Denied: Must be 16 or older.
Ex 3: Even or Odd Number (% 2) 
int number = 27;

// Divisible by 2 with remainder 0?
if (number % 2 == 0)
{
    Console.WriteLine($"{number} is Even (זוגי / زوجي)");
}
else
{
    Console.WriteLine($"{number} is Odd (אי-זוגי / فردي)");
}
> Output: 27 is Odd
🎯
Rule: Exactly one branch runs! If if evaluates to false, C# automatically defaults to the else branch.

🪜 Multi-Way Choices: else if

Multiple Cases HE: ריבוי תנאים AR: شروط متعددة
Ex 4: Score Rating Ladder 
int examScore = 84;

if (examScore >= 90)
{
    Console.WriteLine("Rating: Excellent (A)");
}
else if (examScore >= 80)
{
    Console.WriteLine("Rating: Very Good (B)");
}
else if (examScore >= 70)
{
    Console.WriteLine("Rating: Good (C)");
}
else
{
    Console.WriteLine("Rating: Keep Practicing");
}
> Output: Rating: Very Good (B)
Ex 5: Traffic Speed Monitor 
double currentSpeed = 125.5;

if (currentSpeed > 120.0)
{
    Console.WriteLine("🚨 Danger: Speeding Ticket Issued!");
}
else if (currentSpeed >= 90.0)
{
    Console.WriteLine("Highway Cruising Speed.");
}
else
{
    Console.WriteLine("City / Residential Speed.");
}
> Output: 🚨 Danger: Speeding Ticket Issued!
⚡
Order Matters: C# tests conditions top-to-bottom. The moment one condition matches, its block runs and all others are skipped!

🔗 Compound Conditions: && and ||

Logical AND / OR HE: וגם / או AR: و / أو
&& (AND) - Both Must Be True 
bool hasBossKey  = true;
int  playerLevel = 8;

// Requires BOTH key AND level 5 or higher:
if (hasBossKey && playerLevel >= 5)
{
    Console.WriteLine("Dungeon Door Unlocked! Enter.");
}
else
{
    Console.WriteLine("Door Locked: Need Boss Key AND Level 5+.");
}
> Output: Dungeon Door Unlocked! Enter.
|| (OR) - At Least One Must Be True 
bool isSaturday = true;
bool isHoliday  = false;

// Either Saturday OR Holiday is enough:
if (isSaturday || isHoliday)
{
    Console.WriteLine("No school today! Time to code projects.");
}
else
{
    Console.WriteLine("Regular school day.");
}
> Output: No school today! Time to code projects.
🧠
Quick Cheat: && is strict (all conditions must be true). || is flexible (at least one true condition activates the block).

🧪 Comprehension Check: Predict the Flow

Class Quiz HE: שאלות הבנה AR: أسئلة الفهم
Question 1: What prints to the console?
int score = 95;

if (score >= 70)
{
    Console.WriteLine("Pass");
}
else if (score >= 90)
{
    Console.WriteLine("Honor Roll");
}
Answer: "Pass" (Not Honor Roll!)
Because 95 >= 70 is checked first, C# enters the first branch immediately and ignores all subsequent else if blocks! Always place stricter conditions (90+) before broader ones (70+).
Question 2: Does the alarm sound?
int speed = 85;
bool hasSeatbelt = false;

if (speed > 80 && !hasSeatbelt)
{
    Console.WriteLine("BEEP! Buckle up!");
}
else
{
    Console.WriteLine("All clear.");
}
Answer: "BEEP! Buckle up!"
speed > 80 is true (85 > 80), and !hasSeatbelt is true (NOT false is true). Since both sides of && are true, the alarm triggers.
