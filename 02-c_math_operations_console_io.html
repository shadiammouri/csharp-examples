⚡ Math Operations in C#

Math Operation HE: פעולה חשבונית AR: عملية حسابية
Arithmetic Operators 
// The 5 Core Math Operators:
+  // Addition        (חיבור / جمع)
-  // Subtraction     (חיסור / طرح)
*  // Multiplication  (כפל / ضرب)
/  // Division        (חילוק / قسمة)
%  // Modulo          (שארית / باقي القسمة)
> Work on int, float, and double numbers
Two Variables Blueprint 
// Pattern: Type var1, var2, result
int a = 10;
int b = 3;

int sum    = a + b;  // 13
int diff   = a - b;  // 7
int prod   = a * b;  // 30
int quot   = a / b;  // 3 (integer division)
int remain = a % b;  // 1 (remainder)
> Output: 13, 7, 30, 3, 1
💡
Core Idea: C# calculates right-hand math first, then stores the answer into the left-hand variable.

🖥️ Console I/O: Read & Write

Console I/O HE: קלט ופלט AR: إدخال وإخراج
Console Output: Write vs. WriteLine 
// Console.Write: stays on SAME line (great for prompts)
Console.Write("Enter number: ");

// Console.WriteLine: prints text & moves to NEXT line
Console.WriteLine("Result ready!");

// Clean string interpolation ($"...")
int total = 50;
Console.WriteLine($"Total is: {total}");
> HE: פלט לקונסול | AR: طباعة للشاشة
Console Input: ReadLine & Parse 
// 1. Read input (always returns string text!)
Console.Write("Enter first number: ");
string rawInput = Console.ReadLine();

// 2. Parse text into an int or double for math
int num = int.Parse(rawInput);

// One-line shorthand:
int num2 = int.Parse(Console.ReadLine());
> HE: קלט מהמשתמש | AR: قراءة مدخلات المستخدم
⚠️
Golden Rule: Console.ReadLine() captures text. You must use int.Parse() or double.Parse() before doing math!

⚙️ Statically Set Variables

Static Variables HE: משתנים סטטיים (קבועים בקוד) AR: متغيرات ثابتة في الكود
Ex 1: Score & Penalty (+ / -) 
// Two local int variables
int currentScore = 120;
int bonusPoints  = 45;

int finalScore = currentScore + bonusPoints;

Console.WriteLine($"Score: {finalScore}");
> Output: Score: 165
Ex 2: Area Calculation (*) 
// Rectangle area: width * height
int width  = 15;
int height = 8;

int area = width * height;

Console.WriteLine($"Area: {area} sq units");
> Output: Area: 120 sq units
Ex 3: Modulo Remainder (%) 
// Sharing items equally
int totalCandies = 23;
int students     = 5;

int leftover = totalCandies % students;

Console.WriteLine($"Leftover: {leftover}");
> Output: Leftover: 3
🧠
Takeaway: Modulo % gives the remainder after division. 23 % 5 = 3 because 5 goes into 23 four times with 3 remaining!

🎮 User Input Programs

User Input HE: קליטה מהמשתמש AR: إدخال تفاعلي
Ex 4: Speed Calculator (Division /) 
Console.Write("Enter distance (km): ");
double distance = double.Parse(Console.ReadLine());

Console.Write("Enter hours: ");
double hours = double.Parse(Console.ReadLine());

double speed = distance / hours;

Console.WriteLine($"Average Speed: {speed} km/h");
> Input: 150, 2 ➔ Output: Average Speed: 75 km/h
Ex 5: Shopping Discount Calculator (*, -) 
Console.Write("Enter price: ");
double price = double.Parse(Console.ReadLine());

Console.Write("Enter discount % (e.g. 20): ");
double discountPercent = double.Parse(Console.ReadLine());

double savings = price * (discountPercent / 100.0);
double finalCost = price - savings;

Console.WriteLine($"Final Cost: ${finalCost}");
> Input: 100, 20 ➔ Output: Final Cost: $80
🎯
Pattern: 1. Prompt user with Console.Write. 2. Parse input into variables. 3. Perform math. 4. Display result!

🧪 Comprehension Check: Predict the Math

Class Quiz HE: שאלות הבנה AR: أسئلة الفهم
Question 1: Integer Division & Modulo
int x = 19;
int y = 4;

int divResult = x / y;
int modResult = x % y;

Console.WriteLine($"Div: {divResult}, Mod: {modResult}");
Answer: Div: 4, Mod: 3
19 / 4 = 4 (decimal truncated). 19 % 4 = 3 (remainder because 4 * 4 = 16, and 19 - 16 = 3).
Question 2: Input Without Parsing Trap
// User inputs "5" and then "3"
string a = "5";
string b = "3";

Console.WriteLine(a + b);
Answer: "53" (Text Concatenation!)
Without int.Parse(), the + operator glues text together instead of adding. To get 8, write int.Parse(a) + int.Parse(b).
