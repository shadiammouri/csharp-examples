❓ Question 1: Basic Counter

⭐ Level 1 of 8
C# Code Snippet 
for (int i = 0; i < 4; i++)
{
    Console.Write(i + " ");
}
Challenge

What will be printed to the console when this program executes?

> Output: 0 1 2 3
The loop starts at i = 0 and stops when i reaches 4 because 4 < 4 is false. The number 4 is never printed.
💡
Rule: The condition i < N starting from 0 executes exactly N times (from 0 to N - 1).

❓ Question 2: Initial Condition Check

⭐⭐ Level 2 of 8
C# Code Snippet 
for (int i = 5; i < 2; i++)
{
    Console.WriteLine("Looping: " + i);
}
Challenge

What will be printed to the console when this program executes?

> Output: (Nothing is printed!)
The start state is i = 5. The condition 5 < 2 is tested before the very first round and evaluates to false immediately. The loop body never executes.
🛑
Pre-Condition Test: C# always checks the stop condition before running the body. If it is false at the start, zero iterations occur.

❓ Question 3: Custom Step Increment

⭐⭐⭐ Level 3 of 8
C# Code Snippet 
for (int i = 2; i <= 11; i += 3)
{
    Console.Write(i + " ");
}
Challenge

What will be printed to the console when this program executes?

> Output: 2 5 8 11
Counter starts at 2 and steps by +3 each round: 2 (+3) ➔ 5 (+3) ➔ 8 (+3) ➔ 11. The next step is 14, where 14 <= 11 is false.
➕
Step Flexibility: Increments are not limited to i++. You can jump by any amount, such as i += 3 or i += 10.

❓ Question 4: Countdown Boundary

⭐⭐⭐⭐ Level 4 of 8
C# Code Snippet 
for (int i = 6; i > 0; i -= 2)
{
    Console.Write(i + " ");
}
Challenge

What will be printed to the console when this program executes?

> Output: 6 4 2
The values of i are 6, 4, 2. When i decreases to 0, the strict inequality 0 > 0 evaluates to false, so 0 is never printed.
⚠️
Boundary Watch: Notice the strict inequality > 0 vs >= 0. Strict > 0 excludes 0 from the output.

❓ Question 5: Loop + "if" Filter

⭐⭐⭐⭐⭐ Level 5 of 8
C# Code Snippet 
for (int i = 1; i <= 6; i++)
{
    if (i % 2 != 0)
        Console.Write(i + " ");
}
Challenge

What will be printed to the console when this program executes?

> Output: 1 3 5
The condition i % 2 != 0 checks for odd numbers. When i is 2, 4, or 6, the condition is false and the print statement is skipped.
🔍
Selective Execution: The loop visits all 6 numbers, but the nested if statement selectively executes the print for only matching values.

❓ Question 6: Loop & Condition Tracing

⭐⭐⭐⭐⭐⭐ Level 6 of 8
C# Code Snippet 
for (int i = 1; i <= 5; i++)
{
    if (i > 10)
        Console.WriteLine("Big: " + i);
}
Challenge

What will be printed to the console when this program executes?

> Output: (Nothing is printed!)
The loop repeats exactly 5 times (for i = 1, 2, 3, 4, 5). However, during all 5 rounds, i > 10 is always false, so no output is ever generated!
🧠
Tracing Nuance: A loop can be actively running while producing zero visible side effects if its internal if conditions are never satisfied.

❓ Question 7: Conditional Sum

⭐⭐⭐⭐⭐⭐⭐ Level 7 of 8
C# Code Snippet 
int sum = 0;
for (int i = 1; i <= 5; i++)
{
    if (i != 3)
        sum += i;
}
Console.WriteLine(sum);
Challenge

What will be printed to the console when this program executes?

> Output: 12
The loop cycles through 1, 2, 3, 4, 5. When i == 3, the condition i != 3 is false, skipping 3. The final sum is 1 + 2 + 4 + 5 = 12.
🎯
Accumulation Tracing: When tracing loops on exams, write down the value of sum after each iteration to avoid mental calculation slips.

❓ Question 8: Alternating Accumulator

⭐⭐⭐⭐⭐⭐⭐⭐ Level 8 of 8
C# Code Snippet 
int total = 0;
for (int i = 1; i <= 6; i++)
{
    if (i % 2 == 0)
        total += i;
    else
        total -= i;
}
Console.WriteLine(total);
Challenge

What will be printed to the console when this program executes?

> Output: 3
• Round 1 (i = 1, odd): total = 0 - 1 = -1
• Round 2 (i = 2, even): total = -1 + 2 = 1
• Round 3 (i = 3, odd): total = 1 - 3 = -2
• Round 4 (i = 4, even): total = -2 + 4 = 2
• Round 5 (i = 5, odd): total = 2 - 5 = -3
• Round 6 (i = 6, even): total = -3 + 6 = 3
When i = 7, the loop ends. The final value printed is 3.
💡
Alternating Accumulator: Parity check i % 2 == 0 splits execution into adding even numbers and subtracting odd numbers, without modifying the loop variable i.
