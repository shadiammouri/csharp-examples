🔁 Why & When: C# "for" Loops

Loop HE: לולאה AR: حلقة تكرار
❌ The Problem: Copy-Pasting Code 
// Need to print a countdown or 100 game items?
Console.WriteLine("Player 1 Ready!");
Console.WriteLine("Player 2 Ready!");
Console.WriteLine("Player 3 Ready!");
// ... repeating this 100 times is error-prone
// and impossible for dynamic quantities!
> Clutters code, hard to edit, inflexible
✅ When to Use a "for" Loop 
// Use a "for" loop whenever you know IN ADVANCE
// how many times a task needs to repeat:

// 1. Repeating an exact count (e.g. 10 rounds, 5 laps)
// 2. Stepping through a range of numbers (1 to 100)
// 3. Counting down (10 down to 1 for rocket launch)
// 4. Processing arrays and lists of items
> Rule: Known repetition count = for loop!
💡
Core Idea: Instead of writing repetitive code manually, a for loop lets you write the action ONCE and command C# to repeat it automatically.

🏗️ Structure of a "for" Loop

Loop Structure HE: מבנה הלולאה AR: بنية حلقة التكرار
The 3 Core Components 
//   (1) START STATE   ; (2) STOP CONDITION ; (3) INCREMENT
for (int i = 1         ; i <= 5             ; i++)
{
    // (4) LOOP BODY: Executes every valid round
    Console.WriteLine($"Round: {i}");
}

// 1. START STATE:    int i = 1 (Runs ONCE at beginning)
// 2. STOP CONDITION: i <= 5    (Tested BEFORE each round)
// 3. INCREMENT:      i++       (Executed AFTER each round)
> HE: אתחול ➔ תנאי עצירה ➔ קידום
Execution Lifecycle (Behind the Scenes) 
// Exact sequence C# follows step-by-step:

// Step 1: Initialize Start State (int i = 1) - ONLY ONCE!
// Step 2: Test Condition (Is i <= 5 ?)
//         ➔ TRUE:  Run the body code inside { }
//         ➔ FALSE: EXIT the loop immediately!
// Step 3: Run Increment (i++) to advance counter
// Step 4: Jump back to Step 2 and test again!
> Cycle: 1. Init ➔ 2. Check ➔ 3. Body ➔ 4. Step ➔ Repeat
⚙️
Anatomy Rule: for (Start; Condition; Step) — Initializer sets the counter, Condition decides whether to continue, and Step moves the counter forward.

🏃 Ex 1: Basic Counting (1 to 5)

⭐ Level 1 of 8 (Basic)
Counting Laps Around the Track
Increment HE: קידום מונה (i++) AR: زيادة العداد 
// Loop starts at i = 1, runs while i <= 5, increases by 1 each round
for (int lap = 1; lap <= 5; lap++)
{
    Console.WriteLine($"Lap {lap} completed! Keep running!");
}

Console.WriteLine("🏁 Race Finished! Great job!");
> Output: Lap 1 completed! ➔ Lap 2 ➔ Lap 3 ➔ Lap 4 ➔ Lap 5 ➔ Race Finished!
📌
How it steps: lap begins at 1. After printing, lap++ turns it into 2, 3, 4, 5. When it hits 6, 6 <= 5 is false and the loop terminates.

🚀 Ex 2: Rocket Countdown (i--)

⭐⭐ Level 2 of 8 (Decrement)
Counting Backwards with Decrement
Decrement HE: הפחתה (i--) AR: إنقاص العداد 
Console.WriteLine("Mission Control: Launch countdown initiated!");

// Start at 5, stay in loop while count >= 1, subtract 1 each round:
for (int count = 5; count >= 1; count--)
{
    Console.WriteLine($"T-minus {count}...");
}

Console.WriteLine("🔥 LIFTOFF! Spacecraft launched into orbit!");
> Output: T-minus 5... ➔ 4... ➔ 3... ➔ 2... ➔ 1... ➔ LIFTOFF!
🎯
Key Mechanism: Use count-- to count down. Always ensure your condition tests for the lower bound (e.g., count >= 1) to prevent an infinite loop!

➕ Ex 3: Accumulator (Sum of 1 to 10)

⭐⭐⭐ Level 3 of 8 (Accumulator)
Summing Numbers with an External Total
Accumulator HE: צובר סכום AR: مجمع المجموع 
// Declare the accumulator variable OUTSIDE the loop:
int totalSum = 0;

// Add every number from 1 up to 10 into totalSum:
for (int i = 1; i <= 10; i++)
{
    totalSum += i; // Same as: totalSum = totalSum + i
}

Console.WriteLine($"The total sum of numbers 1 to 10 is: {totalSum}");
> Output: The total sum of numbers 1 to 10 is: 55
🧠
Scope Trap: Always declare totalSum before the loop! If you declare it inside, it gets reset to 0 every iteration.

🔍 Ex 4: Loop + "if" Filter (Even Numbers)

⭐⭐⭐⭐ Level 4 of 8 (Filter)
Filtering Values with Modulo (%) Inside a Loop
Filter HE: סינון תנאי בתוך לולאה AR: تصفية الشروط داخل الحلقة 
Console.WriteLine("Scanning numbers from 1 to 12 for EVENS:");

for (int num = 1; num <= 12; num++)
{
    // "if" condition tests if number divided by 2 has 0 remainder:
    if (num % 2 == 0)
    {
        Console.WriteLine($"Found Even Number: {num} (זוגי)");
    }
}
> Output: Found Even: 2 ➔ 4 ➔ 6 ➔ 8 ➔ 10 ➔ 12
⚡
Combining Power: The loop visits every number; the if condition filters out which ones get printed or processed.

🎯 Ex 5: Target Search with "break"

⭐⭐⭐⭐⭐ Level 5 of 8 (Search)
Early Loop Termination with "break"
Break HE: יציאה מוקדמת מהלולאה AR: إنهاء مبكر للحلقة 
int targetScore = 7;

for (int attempt = 1; attempt <= 10; attempt++)
{
    Console.WriteLine($"Checking chest #{attempt}...");

    // If we find our target, stop wasting time and exit!
    if (attempt == targetScore)
    {
        Console.WriteLine($"🏆 Treasure unlocked at chest #{attempt}! Stopping search.");
        break; // Immediately stops the loop!
    }
}
> Output: Checking 1... ➔ 2... ➔ ... ➔ Treasure unlocked at chest #7! Stopping search.
🛑
Efficiency: break saves computer power. Once your condition finds what you need, exit immediately instead of running remaining rounds!

⌨️ Ex 6: User-Driven Math Table

⭐⭐⭐⭐⭐⭐ Level 6 of 8 (Dynamic)
Combining Console Input with a Multiplication Loop
User Input HE: קלט דינמי AR: إدخال ديناميكي 
Console.Write("Enter number for multiplication table: ");
int tableNum = int.Parse(Console.ReadLine()); // e.g. User types 8

Console.WriteLine($"=== Multiplication Table for {tableNum} ===");

for (int mult = 1; mult <= 10; mult++)
{
    int product = tableNum * mult;
    Console.WriteLine($"  {tableNum} x {mult,2} = {product,3}");
}
> Input: 8 ➔ Prints: 8x1=8, 8x2=16, 8x3=24 ... 8x10=80
🚀
Flexibility: By reading the number from Console.ReadLine(), the loop works dynamically for any number the student chooses!

📊 Ex 7: Pass / Fail Grade Counter

⭐⭐⭐⭐⭐⭐⭐ Level 7 of 8 (Counter)
Looping with if / else and Tracking Multiple Tallies
Tally HE: ספירת מונים AR: إحصاء النتائج 
int passedCount = 0;
int failedCount = 0;

// Step through student grades by +15: (45, 60, 75, 90)
for (int grade = 45; grade <= 90; grade += 15)
{
    if (grade >= 60)
    {
        passedCount++;
        Console.WriteLine($"Grade {grade}: PASS (עובר / ناجح)");
    }
    else
    {
        failedCount++;
        Console.WriteLine($"Grade {grade}: FAIL (נכשל / راسب)");
    }
}
Console.WriteLine($"Total Passed: {passedCount} | Total Failed: {failedCount}");
> Output: Grade 45: FAIL, 60: PASS, 75: PASS, 90: PASS | Passed: 3, Failed: 1
📈
Data Analytics: Combining loops with if/else counters is how real software calculates test averages and attendance statistics!

⭐ Ex 8: Nested Loop Star Pattern

⭐⭐⭐⭐⭐⭐⭐⭐ Level 8 of 8 (Nested)
Loop Inside a Loop for Rows and Columns
Nested HE: לולאות מקוננות AR: حلقات متداخلة 
int totalRows = 4;

// Outer loop controls the ROW:
for (int row = 1; row <= totalRows; row++)
{
    string stars = "";

    // Inner loop controls how many STARS per row:
    for (int col = 1; col <= row; col++)
    {
        stars += "* ";
    }
    Console.WriteLine(stars);
}
> Output: Prints 4 rows: * ➔ * * ➔ * * * ➔ * * * *
🧱
2D Thinking: The outer loop changes the line; the inner loop fills the line. This is how 2D game grids and pixels work!

🧪 Comprehension Check: Predict the Loops

Quiz HE: שאלות הבנה AR: أسئلة الفهم
Question 1: How many times does this loop run?
for (int i = 0; i < 6; i += 2)
{
    Console.WriteLine(i);
}
Answer: Exactly 3 times!
Values of i are 0, 2, and 4. When i becomes 6, the condition 6 < 6 is false, so it stops.
Question 2: What is the final value of "total"?
int total = 0;

for (int i = 1; i <= 4; i++)
{
    if (i != 3) total += i;
}
Console.WriteLine(total);
Answer: 7
The loop visits 1, 2, 3, 4. When i == 3, the if condition skips addition. Total = 1 + 2 + 4 = 7.
